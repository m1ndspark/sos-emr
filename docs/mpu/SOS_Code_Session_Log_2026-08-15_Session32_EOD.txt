PART 2 - THE BIG ONE: THE SAVINGS MODEL WAS WRONG
===============================================================

WHAT HAPPENED
Neil asked to extend hospital benchmarks beyond the four we had. Pulling
the actual CY2026 CMS files to do that revealed the existing model was
structurally wrong and had been since April.

THE ERROR
Every report from April through July used a twelve-line itemized stack
summing an ED facility visit, labs, imaging, ultrasound guidance,
observation, and the procedure facility fee. Under CY2026 OPPS,
paracentesis (49083) and thoracentesis (32557) carry status indicator J1,
the primary procedure of a Comprehensive APC. Medicare pays ONE amount
covering every covered Part B service on the claim. Our stack added those
services on top of a payment that already included them. Every hospital
total was double-counted.

HOW IT WAS VERIFIED
Neil pulled six CMS file sets across the session. The decisive one was
the CY2026 NFRM OPPS Addenda, which contains Addendum D1 (status
indicator definitions) and Addendum J (the C-APC Payment Policy
Exclusions list, 14 entries). Those two files settled everything.

- J1 verbatim: "all covered Part B services on the claim are packaged
  with the primary J1 service for the claim, except the Comprehensive APC
  payment policy exclusions found in the most recent Addendum J."
- J2 verbatim: "Packaged APC payment if billed on the same claim as a
  HCPCS code assigned status indicator J1." So the ED visit packages.
- Where no J1 exists (catheter, G-tube), J2 clause (1) makes the ED visit
  itself the comprehensive payment.
- Ambulance is the ONLY line in our stacks outside the packaging.
- Status K drugs (albumin P9047) are NOT excluded, so albumin packages.
  Two other AI models told Neil it pays on top. It does not.
- Status R blood products are not excluded either.

THINGS OTHER AI MODELS GOT WRONG, CAUGHT AGAINST THE FILES
- Mileage quoted at $8.80; the AFS file says $9.33 urban, $9.42 rural.
- Albumin quoted at $185-$370; P9047 is $53.324 per 50 mL (12.5 g), so
  30-40 g is $159.97-$213.30.
- 99284 quoted at 4.15 RVU / $138.61; the file says 3.54 RVU / $123.46.
- 99283 quoted at 3.05 RVU / $101.87; the file says 2.08 RVU / $72.42.
- 88112-26 quoted at 1.45 RVU / $48.43; the file says 0.78 RVU / $25.90.
- A wage-index table contained a chained arithmetic error - it computed a
  factor of 0.9052 from wage index 0.8420, then reused 0.9052 as the wage
  index on the next line.
- One adjudication cited 42 CFR 419.32 as the C-APC packaging authority.
  419.32 is only conversion-factor arithmetic. The packaging rule is
  419.2(b); the C-APC construct lives in the final rule preamble.
- 49083 has PC/TC indicator 0, so modifier -26 does not apply to it. That
  one was my error, caught by the adversarial review.

WAGE INDEX - A CLEAN FINDING
Every Florida CBSA carries wage index 1.0369. The state rural floor lifts
all of them to the same value - Orlando's pre-floor is 0.9568, Tampa's
0.8776, Pensacola's 0.7784, all overridden. There is no geographic
variation to model in Florida. At the 60% labor share the factor is
1.02214.

THE FINANCIAL RESPONSIBILITY POINT - THE WHOLE POINT OF THE REPORT
For a patient on the Medicare hospice benefit, care related to the
terminal diagnosis is the HOSPICE's financial responsibility, not
Medicare's. Hospitals bill hospices under private contract; non-contracted
facilities bill chargemaster rates far above Medicare allowable. Our
figures are therefore a conservative FLOOR on avoided cost, never a
ceiling. That is now stated in every clinical report.
