## Context docs to update

`context/05_deluge_learnings.md` — append:

- `cancel submit` takes no message argument; use `alert` immediately before it.
- Deluge `insert into` does not fire form workflows — set derived fields inline.
- Setting a field via Deluge does not fire that field's On User Input workflow.
- Lookup display formats cannot traverse two hops; denormalize into a text
  field on the intermediate form.
- On Validate beats On Success for derived fields that don't need the record ID.
- Creator's mobile offline mode blocks any form carrying before-submit
  workflows, so `Encounter_PatientVisit` and `Referrals_Main` can never be
  offline-capable.
- Zoho Forms cannot map into a Creator lookup field. Public submissions always
  arrive with `Partner_Link` and `Partner_Branch_Link` empty — this is the root
  cause of the missing branch links on 37 referrals. Zoho Forms also cannot
  query Creator mid-form, so live email recognition is impossible inside a
  Zoho Form.
