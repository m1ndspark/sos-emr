=== 4. LEARNINGS (Creator v6) ===

- Custom API link name is case-sensitive (Widget_Today_Visits). Widget call: ZOHO.CREATOR.DATA.invokeCustomApi({api_name, workspace_name, http_method}).

- Visit_Status field static choices = 5; the form adds per-type choices on load (Completed, Ordered, Report Sent, Pending Info). API saves of those values unverified.
