PART 3 - RESEARCH FINDINGS (Creator v6 limits, all verified)
=====================================================
- zoho.loginuserid returns the PORTAL login email in a portal
  session and the WORK email in a licensed session. Verified both
  ways with a temporary diagnostic workflow. No portal detection
  is needed anywhere.
- thisapp.portal.loginUserEmailid() returns a list,
  thisapp.portal.loginUserName() returns text,
  thisapp.portal.isUserInProfile() returns boolean. All empty in a
  licensed session. None are callable from a report or permission
  filter.
- Report filters accept STATIC values only. Field == zoho.loginuserid
  is not possible as a report filter.
- Permissions offer only "View" (records the user added) and
  "View all". No criteria option, for app users or portal users.
- Creator's Users field can list Customers (portal users) and be
  designated record owner. Noted as an alternative, not built.
- Page variables (Variables tab plus the single page script) can be
  referenced in an embedded report filter as ${variable_name}.
  One script per page, read only.
- Snippet syntax is <%{ deluge %> html <% }%> with <%=var%>
  interpolation. There is no return statement in a snippet.
- Google Sheets custom number format uses 0 for a required digit,
  not #. Phone mask is (000) 000-0000.
