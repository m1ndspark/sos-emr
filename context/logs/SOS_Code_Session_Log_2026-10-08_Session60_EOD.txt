=== 7. LEARNINGS ===
- Dropdown static choices gate API and widget saves; ui.add choices only exist on the form. Add static choices, then clear + ui.add on load to filter per type.
- Custom API scope All excludes portal users ("The specified user does not exist"); use Portal users scope for portal widgets.
- All HTML snippets on one page share one statement budget; never run a heavy metrics function in more than one snippet.
- Widget iframe is cross-origin: Chrome tools cannot read its DOM or network; surface errors inside the visible widget area.
- Widget zip upload: plugin-manifest.json + app/ at zip root; can be packed without zet.
- unzip in a connected folder fails (no delete permission); overwrite files in place instead.
